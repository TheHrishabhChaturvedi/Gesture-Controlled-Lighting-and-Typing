# Gesture-Controlled-Lighting-and-Typing
The gesture-controlled lighting system developed using OpenCV and Arduino presents an innovative solution for intuitive, touchless control of LED lighting. By mapping the number of raised fingers (from 1 to 5) to specific lighting patterns, the system offers a seamless and accessible interface for smart lighting applications.
 Its design is particularly beneficial for elderly individuals or those with physical challenges, reducing dependency on traditional switches and promoting greater independence. Beyond basic lighting control, the system is capable of detecting and interpreting numeric inputs based on finger count, opening possibilities for gesture-based PIN entry, authentication, and virtual typing interfaces. This dual functionality—combining physical device control with data input—demonstrates the system's versatility in human-computer interaction. Potential use cases include smart homes, interactive kiosks, public terminals, and other environments where hygiene or accessibility is a priority.
